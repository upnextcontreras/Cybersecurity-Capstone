## Project Phases

### Phase 3: Cloud Migration Strategy, Execution, and Post-Migration Review

**Objective:** Oversee ACME Corporation's transition from on-premises infrastructure to the cloud, execute the initial batch migration, evaluate success, and drive cultural transformation within the Information Security Department.

#### Key Activities:

##### Migration Planning and Execution
* Perform a detailed pre-migration review of the initial batch:
  * Kali Linux Cyber Lab VM
  * Windows Server 2022 (Domain Controller)
  * Metasploitable VM
* Harden and secure all VMs before migration (OS hardening, patching, access control)
* Select and set up a cloud environment (AWS, Azure, or GCP)
* Design a secure network layout for the cloud environment
* Draft a migration timeline for both initial batch and full migration (~20 VMs)
* Complete post-migration validation and auditing

##### Post-Migration Review and Analysis
* Reflect on migration execution challenges and resolutions
* Justify the necessity of migration for ACME's long-term success
* Compare cloud providers and justify your selection
* Provide a cost analysis for running initial batch systems in the cloud

##### Departmental Transformation
* Address broader departmental issues:
  * Overcome "peacetime" complacency
  * Reduce siloed operations
  * Establish ongoing security awareness training
  * Mitigate risks from shadow IT
* Propose next steps for full-scale modernization
* Support the security team cultural shift with actionable recommendations

#### Deliverables:
* Migration Timeline (PDF/DOCX/JPG/PNG)
* Migration Plan Document (includes network design, risk assessment, security considerations)
* Post-Completion Write-Up with Lessons Learned (PDF/DOCX)
